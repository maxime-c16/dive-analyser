# Playback hardening — 9 November 2026

The requested wider engineering and UI audit is ongoing. This first change fixes
session-video recovery and shared transport state; it does not establish that
all routes, media types or devices are production ready.

## Live observations

Used the dedicated E2E account through the public HTTPS app, without changing
library content. Library loaded and an existing 101B clip reached readyState 4,
played, and reported 406 × 720 video dimensions. At desktop 1280 × 800 and
375 × 667 CSS viewport sizes the page had no horizontal overflow. At the narrow
size transport bounds were x=14, y=551, width=347, height=40, within the viewport.
The narrow check resizes desktop Chromium; it does not certify iOS decoding or
touch behavior. No source changes have been deployed by these observations.

## Confirmed code defects and invariant

A network-error refresh in SessionVideoPlayer restored position but omitted
playback restart and speed restoration. Preserve position, selected speed and
whether the viewer was playing across the bounded refresh. Failed-load and
source-replacement pause events must not erase playing intent. Resume once on
canplay; if browser policy rejects play, leave the play button available.
Intentionally paused videos remain paused.

ImmersiveControls subscribed to play/pause but omitted ended, durationchange
and emptied. The shared transport must reflect the native element when a
non-looping session finishes and as its duration changes.

Regression tests cover playing/paused recovery, source replacement pausing,
position and speed restoration, duplicate canplay events, ended state and
updated scrub duration. Existing bounded refresh/fallback tests remain.

## Expanded media workspace pass

The gallery now uses an explicit recording grid and selected-player layout,
with desktop columns and a stacked phone layout. Recording filenames,
previous/next navigation, keyboard focus restoration, translated management,
inline delete confirmation and recoverable page errors replace the former
horizontal strip. Pagination is single-flight and deduplicated. A new session
or guest capability remounts the workspace; late requests are ignored. Bulk
downloads stop scheduling on unmount, session refresh or explicit cancellation.

Shared player controls now provide fullscreen (including their controls),
focused left/right seeking with finite duration bounds and M mute. Shortcuts
ignore modifier combinations and consume handled keys before viewer navigation.

Live shared-session API returned 404 for the E2E account: no feature flag was
changed. The new gallery was inspected locally with seven synthetic recordings,
without uploading or mutating production data. Desktop and 375px phone layout
checks covered the grid, selected player and focus; synthetic clips do not
prove real session-media decoding or production availability.
