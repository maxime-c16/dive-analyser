# Structural direction after round 4

User mandate: a professional diving product that a new adult can understand without learning a social-feed interface. Applies to the main journeys and their children; legacy routes retain their behavior.

The content hierarchy is task → controls → footage/data → secondary detail. Navigation names its five destinations. Library modes are named consistently at every size. Playback keeps transport, next/back and return controls available; gestures remain optional shortcuts. Scoring distinguishes a draft, a submitted score and a missed deadline. Utility loading is neutral rather than playful.

Palette: deep water #101820; slate #17232d; raised slate #1c2b36; boundary #344651; text #eff4f7; marine blue #78bfd1. Existing sans family, 28px page titles, 18–20px section headings, 14–16px task content and 13px metadata. No decorative entrance animation, ornamental uppercase labels or floating pill navigation.

Phone/tablet: attached full-width named navigation above content; five destinations visible. Desktop: existing labeled sidebar, quiet borders. The previous short-height icon rail is superseded. Main content is left aligned; video retains the largest uninterrupted viewing area available.

Library:
    Library                         Add videos
    Videos | By dive code | Progress
    Scope / Search / Filters        Grid | List (Videos only)
    Footage or requested analysis

Evaluation:
    Evaluations                     Group judging
    My dives | Review dives | My reviews
    Attempt identity → review state → selection control

Validation is separate from this direction: no new council score is asserted before a fresh review of the corrected SHA. Existing 6cb6 scores are immutable historical judgments.
